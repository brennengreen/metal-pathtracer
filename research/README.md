# Research: Neural Ray Amplification

Pipeline that tests whether one physically cast ray + inference can stand in for many
path‑traced samples. Full write‑up and results: **[REPORT.md](REPORT.md)**.

## Files
* `model.py` — the amplifier MLP (Fourier‑encoded G‑buffer, log‑radiance residual head).
* `train.py` — load the exported dataset, train on training views, evaluate on held‑out
  views; writes `results/metrics.json`, `results/comparison.png`, `results/model.pt`.
* `eval_amplify.py` — rigorous effective‑sample measurement from a held‑out Monte‑Carlo
  stack; writes `results/amplify.json`, `results/convergence.png`.

## Data (generated by the Metal tracer)
* `--export` → `data/{X.bin,Y.bin,meta.json,cameras.json}` (per‑pixel features + targets).
* `--samplestack` → `stack/{stack.bin,ref.bin,feats.bin,stack_meta.json}` (held‑out view).

## Quick start
```bash
pip install -r requirements.txt        # torch, numpy, matplotlib, pillow
# (from repo root, after `swift build -c release`)
./.build/release/pathtracer --export --scene cornell --width 256 --height 256 \
      --views 16 --targetSpp 512 --bounces 6 --clamp 8 --out research/data
cd research && python3 train.py --data data --out results --epochs 60
cd .. && ./.build/release/pathtracer --samplestack --scene cornell --view 15 \
      --width 160 --height 160 --stackM 256 --refSpp 2048 --data research/data --out research/stack
cd research && python3 eval_amplify.py --stack ../research/stack --model results --out results
```
